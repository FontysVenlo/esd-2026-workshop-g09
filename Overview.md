| Block/Step | What the student sees on their screen | What we manipulate as Admins |
| :--- | :--- | :--- |
| **1. Architecture: Changes a local text value or inspects the WebSocket log to teleport/cheat score.** | Students have access to the inspector tools and can change the x,y values and score of their game. | A Server switch stops the Javascript bridge from taking in new values from the users end. |
| **2. Latency:  the game lags while playing.** | Students will experience rubber-banding and lag everywhere. | We have the latency and packet loss sliders, also able to toggle prediction and interpolation on and off (this will simulate a bad connection). |
| **3. Cheats: the raw packet stream to spot "hidden" players (Read) and drags a speed slider (Time). Debug Menu, to enable ESP, has a speed multiplier slider for increasing speed above normal levels.** | Students gain access to the admin debug menu, (press F6 or something) in the debug menu see many checkboxes and sliders (able to enable ESP, play with the speed slider). "Enable Auto Collect Macro" checkbox & jitter slider will be locked for this step. | We give them access to press F6 to open up the admin debug menu. Once done we revoke access in a “hotfix” patch. |
| **4. Defenses: Pre-built macro button to test the bot detector, then adjusts a jitter slider to bypass it. In the Debug Menu allow access to the "Enable Auto Collect Macro" checkbox.** | "Enable Auto Collect Macro" checkbox will be unlocked for this step. Students can click on the checkbox to enable it and access to the jitter slider. Once they click on the "Enable Auto Collect Macro" checkbox there will be a prompt on the screen saying “Bot detected!” so the students have to reduce the jitter slider to go under the radar. | In the Debug Menu we allow access to the "Enable Auto Collect Macro" checkbox and jitter slider. Now there is no good design fix against this, because the macro sends legal inputs and that is why live admin detection or AI is used here, but it is still all a fairly new approach. |
